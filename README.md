# AeroFlex V2

AeroFlex V2 is an experimental aerospace engineering project studying how wingtip geometry affects aerodynamic efficiency at low Reynolds numbers.

The previous AeroFlex V1 free-flight glider work is preserved under `archive/v1/`. V2 replaces free-flight testing with controlled aerodynamic force measurements so that lift and drag can be measured experimentally for interchangeable wingtip geometries.

Computational analysis will support the physical experiment through planning, checks, and interpretation. It will not predetermine the experimental result, replace force measurements, or assume that any wingtip geometry is superior before evidence is collected.

Airflow uniformity and mounting-system forces will be characterized before aerodynamic comparisons are considered valid.

The project is currently in the experimental-design and airflow-characterization stage. No V2 aerodynamic results have been measured or simulated yet.
