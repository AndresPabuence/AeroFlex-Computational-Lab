# Research Question

How does three-dimensional wingtip geometry affect the aerodynamic efficiency (L/D) of a finite wing operating at low Reynolds numbers?

## Secondary Questions

- How does wingtip geometry affect measured lift across the planned test conditions?
- How does wingtip geometry affect measured drag across the planned test conditions?
- How does angle of attack change the lift, drag, and L/D response for each tested wingtip geometry?
- How do airflow velocity and Reynolds number affect the measured aerodynamic forces?
- Which geometry parameters can be varied repeatably while preserving the same baseline wing and measurement setup?
- Which measured trends remain consistent across repeated trials and uncertainty estimates?

Reynolds number is a derived operating parameter calculated from measured airflow velocity, wing chord, and air properties. It will not be treated as an independently controlled variable in the initial experimental design.

No wingtip design is assumed to be superior. The result must be determined by experimental evidence.
